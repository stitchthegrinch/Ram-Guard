ROBLOX RAM GUARD V7.5

Changes from v7:
- Auto-trim target remains 600 MB.
- Automatic trim now triggers at 700 MB instead of constantly trimming near 600 MB.
- Guard checks every 5 seconds.
- Once a Roblox process has a resolved username/UserId, RAM Guard stops scanning logs for that PID.
- Log scanning continues only for unresolved/Unknown clients.
- Main account uses Above Normal priority instead of High to reduce scheduler contention.
- Existing v7 controls remain available.

Extract the ZIP first, then run:
Launch_Roblox_RAM_Guard.cmd
